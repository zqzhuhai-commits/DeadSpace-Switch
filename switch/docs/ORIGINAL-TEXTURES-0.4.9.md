# 0.4.9：恢复原版材质

根据用户报告，高清替换会导致部分材质不可见。本版固定使用原游戏材质：Switch 游戏入口不注册高清读取/替换回调，既有 hd.cfg 和外部高清目录不再影响该入口。内置 RomFS 使用 1748 个原有数据文件，不包含 texture_hd 目录、53 张高清文件或其清单。高清工具与历史实验代码仍保留供参考，未用于本版游戏启动。

保留中文、现有显示配置、L 跑步/ZL 瞄准、R3 寻路、L3 陀螺开关及方向键下零重力跳跃。保留 modf/ldexp 的 ARM32 兼容修复、所有关卡适用的有限加载预算及修正后的版本标记。自制进度条保持取消。原存档不删除、不重置，不要求重新开档。

实际 ELF 检查版本 0.4.9-Original，软件包控制版本为 0.4.9。原版材质路径的电脑原游戏库/存档恢复回归完成 1500 帧，原生玩家 HUD 就绪，ARM32 modf/ldexp 回归通过，未配置高清回调。最终 NSP 资源回读结果见交付记录；Switch 硬件或模拟器未运行本版，电梯继续推进、设备材质显示及完整剧情仍需验收，不能把回退高清当作所有图形或退出故障均已修复。

若继续使用已有 0.4.7/0.4.8，可先在 /switch/deadspacemobile/hd.cfg 写入单个数字 0 后重启；0.4.9 直接固定原版材质，不需要该配置。

公开提交仅包含代码和说明；游戏资源、用户保存/日志、密钥及资源整合 NSP 均不公开上传。
