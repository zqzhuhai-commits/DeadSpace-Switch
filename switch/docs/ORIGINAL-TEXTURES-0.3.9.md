# 0.3.9 原版材质 / 输入 / 音频测试候选

用户实机反馈：0.3.8 已显示中文，加载明显改善；声音卡顿、左摇杆间歇失效、
右摇杆既不能移动菜单光标也不能转视角，R3 只显示中心十字。此次按要求取消高清替换。

## 输入修正

- `GetDeviceName` 从 Switch 改回 **R800**，制造商保持 sony，型号仍为 Switch。
  这是支持 donor 的 Xperia Play 实体输入模块选择条件，不是显示名称。
  对照项目 `jni/classes/ea_SystemAndroidDelegate.h` 中对同一二进制的说明。
- 原生 libnx 快照直接返回前端事件列表，不再投递到 SDL 的全局控制器事件队列。
- 菜单模式右摇杆移动光标；R3 明确切换光标/游戏模式，+ 打开菜单并保留光标。
  显式打开的光标不会因摇杆移动立刻自动消失。开机光标允许左摇杆主动退出。
- 不因切换菜单而丢弃物理摇杆的持续状态；结束移动时使用上次触点坐标释放。
- L3 继续发送武器旋转手势，R3 不发送武器旋转手势。

## 音频修正

旧实现直接播放空队列，最大只存约 100ms PCM，而且 blocking AudioTrack.write
在剩余队列空间很小时会只接受部分 mixer block。新实现：

- 首次播放及真实欠载后预缓冲 100ms；短末尾块最多等待 150ms。
- 队列容量 250ms，SDL 每块 2048 帧；暂停、清空和恢复维持各自语义。
- 常规 blocking 写入在空间不足时等待重试整个块，避免调用者未处理短写时丢失尾部。
- 周期日志记录 underrun/start 次数与双摇杆实际数值，便于下一轮实机定位。

这些是针对缓冲和写入的修正，不表示已经确认能消除所有 Switch 音频卡顿。
持续性能不足仍可能使任何有限缓冲耗尽。

## 原版材质整合包

沿用已校验的中文 donor 数据及中文字体/英文回退设置，移除全部 texture_hd
高清文件和相关清单条目；没有高清 manifest 时不安装运行时高清替换回调。
游戏库、原版材质和存档路径不改变，不要求删除旧存档。

验证包括 SDL 模式切换/右摇杆光标/持续移动、PCM 预缓冲与欠载恢复/阻塞短写，
再运行完整主机与 Switch CI。原版材质包需重新回读核验。
实际镜头控制、操作感、音频连续性和帧率仍需 Switch 实机验收。
