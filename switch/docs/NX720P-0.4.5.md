# 0.4.5-nx720p

默认请求 1280×720；旧版实机日志为 960×540。新包同时记录请求尺寸和实际 `Native surface`，实际分辨率、文字清晰度和性能需上机确认。文字清晰度也取决于原版字体贴图。

程序首次生成 `/switch/deadspacemobile/display.cfg`，内容 `1280 720`。若 720p 卡顿，可将该文件改成 `960 540` 后重启。已有有效配置会保留。

## 游戏中

| Switch | 游戏动作 |
|---|---|
| 左摇杆 | 移动 |
| 右摇杆 | 视角 / 瞄准 |
| L 或 ZL（按住） | 瞄准；无枪械时不强制进入瞄准 |
| ZR | 瞄准时射击，否则近战 |
| R | 瞄准时切换武器模式 |
| B | 交互 / 拾取 / 确认 |
| A | 动能抓取，再按投掷 |
| Y | 装弹 |
| X | 快速转身；瞄准时静滞 |
| 右摇杆按下 | 零重力跳跃 |
| 左摇杆按下 | 陀螺瞄准开关，默认关闭；开启后仅按住瞄准键时使用 |
| 十字左 / 右 | 上一把 / 下一把武器 |
| 十字上 / 下 | 近战 / 寻路 |
| + / -（松开时） | 暂停 / RIG 背包 |

菜单、暂停、背包、商店和关卡弹窗自动切为指针操作：两个摇杆或十字键移动指针，A 点击/拖动，B 返回。切换界面时释放旧操作，避免刚确认菜单的按键被当作游戏动作。

布局与直接动作/镜头方案参考 [hazevauks/deadspace_nx](https://github.com/hazevauks/deadspace_nx)。该项目支持 Amazon 1.2.0；本包仍使用自己的 Xperia Play 1.1.33 库，入口、参数、HUD 状态、武器检查和 Vector2Event 表均独立核验，没有套用 Amazon 偏移。

本次重做了核心游戏键位，不包含 NX 自有的 + 与 - 设置覆盖层；该组合不再直接退出游戏。陀螺开关本次运行有效，重启默认关闭。陀螺支持掌机、Pro 手柄和成对 Joy-Con 的传感器读取，硬件手感尚待验证。

## 验证与限制

按键回归覆盖菜单/游戏切换、全部核心动作 ID、按住和松开、L/ZL 合并、断连释放、右摇杆不生成伪点击、组合键隔离和陀螺单位转换。Windows 真实游戏库已验证自动进入游戏操作模式，移动、镜头及原生动作调用路径；这是电脑参考，不代表 Switch 键位舒适度或命中/伤害已验收。

安装 `DeadSpace-Mobile-ZH-0.4.5-NX-720p.nsp`，无需清理存档或重复安装启动小包。若仍有错误操作，请说明具体按键、所在界面和触发的实际动作，并提供首条含 `0.4.5-nx720p` 的新 `startup-latest.log`。

Switch 构建和 NSP 全资源回读检查通过；本轮没有在目标机测试新包。密钥、原始资源和游戏整合 NSP 不上传公共仓库。MIT 许可及原作者声明见仓库 NOTICE.md 与 switch/licenses/deadspace_nx-MIT.txt。
