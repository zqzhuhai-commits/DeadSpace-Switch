# 0.4.6：加载提示、R3 寻路与复启动诊断

保留已能进入游戏的 Xperia Play 1.1.33 核心、中文资源和默认 1280×720 请求。已有 display.cfg 仍按其有效配置运行。0.4.4 已由用户确认能进入游戏；本版还需要 Switch 实机验收。

## 加载界面

建立原生图形窗口后立即显示底部状态条；初始化和耳机画面期间继续显示，不遮住整个游戏画面。活动条来回移动，文字显示累计已读资源 MB、已返回游戏帧数及经过秒数。它不是完成百分比，也不承诺剩余时间。进入原生玩家 HUD 后自动收起。

长时间执行的原游戏调用也能在 CPU 执行间隙刷新提示；它没有独立后台动画线程。主线程、驱动或文件系统真正阻塞时，动画仍可能停住，不能用动画保证程序绝不卡死。该版本未改变原游戏加载逻辑，未测得加载提速。

覆盖层仅使用 scissor/clear，保留并恢复剪裁、清屏颜色和颜色写入状态，不改游戏矩阵、纹理、顶点或深度缓冲。内置原创位图英文字形，无额外字体文件依赖。

## 键位

- R3（按下右摇杆）：寻路。
- 方向键下：零重力跳跃，避免与寻路重叠。
- 右摇杆：水平/垂直转速均降为 0.4.5 的 60%，游戏内灵敏度仍参与计算。
- 左摇杆：直接向原游戏玩家发送连续 Vector2Event（pad 1），绕过触控方向盘；保留完整方向角与推杆幅度、圆形死区，松手/断连/进入菜单时发送零向量。不是四向或八向按键组合。入口及写入浮点分量的指令已按当前游戏库逐字核验。具体动画、瞄准和场景仍受游戏规则影响。
- 其余沿用 [0.4.5 键位](NX720P-0.4.5.md)，菜单中的方向键仍移动指针。

## 第二次运行退出的报告

用户报告首次运行正常，第二次运行退出，删除游戏目录后可启动；目录已删除，暂未复现，因此原因未确认，不能标记为修复。保留现有设置与存档，不通过删除目录或重置关卡规避问题。

新增 SAVE STATE / SAVE OPEN 记录，帮助区分设置、关卡和检查点文件读取及存储初始化问题。若再次发生，请在失败后保留整个 `/switch/deadspacemobile` 目录，并复制 startup-latest.log 与 diagnostics.log。
